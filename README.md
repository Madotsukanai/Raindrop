# **Raindrop**
『五月雨〜samidare〜』Ver1.054及び『RefRain - prism memories -』V1.03.7用のステージセレクト等の機能追加パッチです。
## 使い方
### 五月雨
[Releases](https://github.com/Madotsukanai/Raindrop/releases/latest)からddraw.dllをダウンロードし、Rain.exe (SHA-256: ae35b0ad17094bd21f86bc464504ceeafc50941e5207d75a3065e44049138211)と同じディレクトリにコピーしてからゲームを起動して下さい。<br>

グラフィックスAPIは、Rain.exeと同じディレクトリに置く`raindrop.ini`で選択できます。

```ini
[Graphics]
API=DirectDraw
```

`API=DirectDraw`はシステムのDirectDrawを使用します（未対応の場合はD3D9へフォールバックします）。`API=D3D9`にすると内蔵D3D9実装を起動時から使用します。ファイルや設定を省略した場合は`DirectDraw`です。<br>
### RefRain
[Releases](https://github.com/Madotsukanai/Raindrop/releases/latest)からd3d9.dllをダウンロードし、RefRain.exe (SHA-256: db092baa547241a0217ca41be8538672b79094f671884f92a32c06943c857e78)と同じディレクトリにコピーしてからゲームを起動して下さい。<br>
「DIVE 2 M.R.S.」にカーソルを合わせた状態でコンセプトリアクターに割り当てたキーを入力するとプラクティスメニューが開きます。

## 機能
- 入力遅延の軽減
### 五月雨
- Windows 11対応
- PracticeメニューへのExtraの追加

![Practice](https://madotsukanai.github.io/raindrop2.png)

- バグの修正

ゲーム内に存在する、「リザルト表示中にリトライするとスコアが引き継がれる」、「敵弾警告音等の効果音が一部鳴らない」、「リプレイメニューに不可視の選択肢がある」等未修正のバグを修正します。

- 一部環境におけるリプレイズレの修正

リプレイにおける弾や自機の座標を強制的に24bitの浮動小数点で演算させます。

- ショートカットキーの追加

  -  Dキー
     設定画面で押すとデフォルトの設定を呼び出します。
  -  Qキー
     ポーズ画面で押すとタイトル画面に戻ります。
  -  Rキー
     ポーズ画面で押すとリトライします。
  -  alt+Enter
    ウィンドウとフルスクリーンを切り替えます。

- ポーズ画面でのBGM・SE一時停止
- リプレイ再生中のポーズの有効化
- Practice開始時のパワー調整

ステージ2ではパワーが6段階、ステージ3ではMAXになります。

- PracticeメニューへのExtraステージ追加

全ステージクリア後にPracticeメニューからExtraステージが選択可能になり、左右キーでArea 1〜4を選択して各エリアから練習を開始できます。現時点では背景がまだ正常ではありません。

### RefRain
- ショートカットキーの追加
  -  Qキー
     ポーズ画面で押すとタイトル画面に戻ります。
  -  Rキー
     ポーズ画面で押すとリトライします。

- プラクティス

ステージ、残機、M.E.F.A.2ゲージ残量、コンセプトリアクターストック数及びゲージ量を調節可能です。
ステージが終了するとそのキャラのデスクトップに戻ります。
プレイ中にF1〜F5キーを押すと即座に各ステージへ移動できます（スコアやプリズム等はリセットされます）
